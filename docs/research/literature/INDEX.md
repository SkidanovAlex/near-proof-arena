# Literature catalogue — index

Indexed, maintained record of the papers, code and systems relevant to NEAR Proof's goal: one succinct post-quantum proof (< 300 KB) of NEAR chunk validation up to 1 Pgas, proved in real time on a few H200s, with soundness ≤ 2⁻¹²⁸ against ≤ 2⁶⁴ quantum queries from proven bounds (contract U-1…U-12, `docs/zk-formal/V3-D3A-STUDY.md` §D). Started 2026-10-18 on `lane/research-catalog`.

* [CATALOG.md](CATALOG.md): one entry per item (citation, link, topics, what it gives, relevance, repo paths, key numbers).
* [OPPORTUNITIES.md](OPPORTUNITIES.md): items we have not exploited, ranked by expected impact, each with a next step.
* [refs.bib](refs.bib): BibTeX for every entry (best effort; keys = tags).
* Related registers: `docs/research/NOVEL-FINDINGS.md` (our own candidate results; use this catalogue for prior-art fields).

**Counts:** 258 items in 11 topics. used 35, evaluated (kept / watch) 62, evaluated-rejected 40, cited only 59, not-yet-evaluated 62.

## How to maintain

* Add an entry to CATALOG.md under its primary topic. Tag: first letters of up to four authors + two-digit year (`CMS19`), or a short system name (`OpenVM`). Add the tag to every relevant topic list below, and a BibTeX record with the same key to refs.bib.
* Mark relevance honestly: `U` only when a lane's code, parameters or proofs depend on it; give the path.
* Record numbers with their security basis (proven / conjectured, classical / PQ, which bound). Never copy a 100-bit or conjectured figure as if it met U-6.
* When a lane evaluates an `N` item, change its code and add the lane path. Move resolved items out of OPPORTUNITIES.md.
* Verify every ePrint/arXiv id against the listing page; entries marked `[unverified]` still need that check.
