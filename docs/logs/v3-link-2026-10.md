## 2026-10-11 (cont.) — Task 1: A7 in the AIR — design (before coding)

Merged `origin/integration/v3-20261011b` (fast-forward to `9bb1a295`).

### The measure

`unfoldBytes cb w = Σ_τ U_τ`, `U_τ = unfoldedBytesT pre_τ + diffT pre_τ post_τ`, where
`pre_τ = partialTrie store root_τ keys_τ`, `post_τ = rebuildPost store out_τ keys_τ`, and

* `unfoldedBytesT t = Σ_{o ∈ occs t} |nodeEnc o| + Σ_{v ∈ valsOf t} |v|` (one term per
  revealed **occurrence**: a shared subtree counts once per path copy);
* `diffT pre post` walks `post` top-down, pairing each post node with the pre node at the
  **same position** (`preExtChild`, `kidAt`, `preLeafSlot`, `preBranchSlot`): a post node is
  counted (`|nodeEnc|` + `slotDiff` of its value slot) iff the pre node there is unrevealed or
  has a different encoding, and the recursion stops below an uncounted node.  `slotDiff`
  counts the post value bytes iff `valueRef = u32 len ‖ sha256 v` changed.  Below a position
  whose pre counterpart is unrevealed (`.hash`) **everything** revealed is counted.

### What the records carry (honest render)

* `nodeV3`: one record per revealed occurrence of `pre_τ` (tree-shaped, duplicates are separate
  records flagged `dup`), one row per byte: `b` = `nodeEnc` (pre), `pb` = the lockstep post
  encoding (account `set`s keep every length, so `|post| = len`), value windows (`tv`) with the
  pre / post value digests `reg` / `preg`.
* `valV3`: one record per revealed value occurrence, one row per byte (`gb`).
* `upsV3`: per τ the new 0x0f value (`L` bytes) and the new path nodes `Q_1 … Q_nQ` (bottom-up;
  upper parts `RDB/RDE/PT` replace the path records `N_d` / empty-key extensions, terminal
  parts create / split the bottom nodes).

So, honestly, **`Σ_τ unfoldedBytesT pre_τ = #active nodeV3 rows + #byte rows (gb) of valV3`**
(exact; duplicates included).  The diff term is the hard part:

1. lockstep: an off-path record `r` contributes `len_r + [vchg]·vlen` iff its post copy is
   counted by `diffT`, i.e. `pb ≠ b` (or moved, 3.) and its post parent is counted;
2. path positions: the final post node is `Q_j`, not the record's lockstep `pb`; it is counted
   iff `Q_j ≠ nodeEnc (pre node at that position)` and its parent part is counted; the new
   0x0f value iff its `valueRef` differs from the old value's;
3. splits (0x0f absent and the `[0]` subtree a single extension / leaf): the subtree under the
   split point **moves** (its pre counterpart is `.hash`), so every revealed record below it,
   changed or not, and all its revealed values are counted.

### Option E — exact in-AIR `diffT` (what "in-AIR unfold accounting" requires literally)

New columns/flags (all one-sided lower bounds, so soundness = "every `diffT`-counted item is
AIR-counted", completeness = the honest minimal assignment equals `diffT`):

* `nodeV3`: record constants `cnt` (post copy counted), `pin` (parent counted, received),
  `mv` (moved), `rpl` (replaced by an upper ups part), `rq` (that part's count); per value
  window `vchg` with `(1 − vchg)(reg_i − preg_i) = 0`;
  constraints `(1 − cnt)·pin·(b − pb) = 0` (every row), `(1 − cnt)·mv = 0`;
  new chained bus `PCNT (cid, pout, mv)` sent by every revealed child window and received on
  the child's first row, `pout = rpl ? rq : cnt`; the head sends `PCNT (rid, 1, 0)`;
  new `RPL (nid, qcnt)` received iff `rpl`; new `MV (nid)` received iff the record is a
  moved-subtree root; running sums `ra` (all rows) and `rd` (`cnt·(1 − rpl)` rows +
  `cnt·vchg·vlen` + `mv·vlen` on value windows) sent on new `SIZE` tags.
* `upsV3`: per part `qeq` / `qcnt` with `(1 − qcnt)·qpin·(1 − qeq) = 0` and `qeq` ⇒ every byte
  equals the source record's **pre** byte at the same position — needs a new chained provider
  of pre bytes `UPR (NPRE(n), pos, b, u)` on `nodeV3` (UPB carries only `pb`); sends
  `RPL (cN, qcnt)` per upper part and `MV (c)` for the moved child of a split case; the new
  value's change flag needs the old/new 0x0f value equality, which only the scheduler codec
  (`schV3`, both encodings row by row) can decide — a flag `eqS` there, sent to `upsV3`.
* `valV3`: running sum over `gb` rows, sent on a new `SIZE` tag.
* `sizeV3`: receive the new tags and range-check `B0 − Σ ≥ 0` (24 bits; `B0 < 2^24`).

Exact identity proved per instance (to be proved, part of the link):
`Σ_rows ra + Σ val gb + Σ rd + Σ_ups qcnt·qlen + [vchgL]·L  =  U_τ` for the honest render, and
`≥ unfoldBytes cb (witnessOfV3 k x)` for any accepted trace.

Cost: 6 tables change (`nodeV3`, `valV3`, `upsV3`, `headV3`, `schV3`, `sizeV3`), ≈ 12 new
columns and 8 new interactions on `nodeV3` alone, three new buses; all their renders change.

### Option S — change the A7 measure (spec, needs the user)

Measure `A7′`: `Σ_τ unfoldedBytesT pre_τ + unfoldedBytesT post_τ` (pre plus the **whole**
revealed post trie, no position matching).  `diffT ≤ unfoldedBytesT post` (each counted post
node is a distinct post occurrence; `slotDiff ≤` its value bytes), so `A7′ ≤ B` implies the
current A7 — soundness transfers; the domain shrinks only for witnesses near `B0` (honest max
50,579 B → ≈ 100 kB, still 20× under `B0`).  In-AIR it is exact with **no comparisons**:
`#nodeV3 rows + Σ (1 − rpl)·len + Σ_ups qlen + val bytes (pre) + val bytes (post) − [old 0x0f
value replaced]·len + L`; changes: `nodeV3` (`rpl` + `RPL` recv + two running sums), `upsV3`
(`RPL` send), `valV3` (running sum), `sizeV3` (new tags).
