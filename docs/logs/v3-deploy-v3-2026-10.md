### Build hazard (not a live issue; for whoever builds next)

At first I seeded the private target dir with a copy of the shared `~/.cache/nearproof-live-target`,
which `judge-fc-batch` had built at `dd55a305`. Cargo reported every workspace crate **fresh** in
0.1 s. The dep-info paths resolve against the new worktree, and its sources are older than those
outputs. So the binaries would have been judge-fc-batch's Firecracker code stamped as `a8c55352`.
`check_stamp` cannot catch this. I deleted that dir and did a clean build. Do not copy or share
a target dir between lanes for `arena-live build`.
